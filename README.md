# C语言术语 中韩对照 · C 언어 용어 중한 대조

一个纯静态的单页网站，用中文和韩语对照学习 C 语言专业术语和相关知识。
中국어와 한국어를 나란히 놓고 C 언어 용어와 관련 지식을 익히는 정적 단일 페이지 웹사이트입니다.

**在线预览 / 온라인 데모**: `https://<你的用户名>.github.io/<仓库名>/`（部署后把这行改成你的地址）

## 本地运行 / 로컬 실행

只有一个文件，直接用浏览器打开 `index.html` 即可，不需要安装任何东西。
파일 하나뿐입니다. `index.html`을 브라우저로 열면 바로 동작하며, 별도 설치가 필요 없습니다.

## 部署到 GitHub Pages / GitHub Pages 배포

1. 把这个仓库推送到 GitHub。/ 이 저장소를 GitHub에 올립니다.
2. 仓库页面 → **Settings** → **Pages**。/ 저장소 페이지 → **Settings** → **Pages**.
3. **Source** 选 *Deploy from a branch*，分支选 `main`，目录选 `/ (root)`，点 **Save**。/ **Source**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)` 선택 후 **Save**.
4. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。/ 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/`에서 확인합니다.

## 添加或修改术语 / 용어 추가·수정

所有数据都在 `index.html` 的 `<script>` 里。/ 모든 데이터는 `index.html`의 `<script>` 안에 있습니다.

```js
// TERMS 数组里加一条 / TERMS 배열에 항목 추가
{ i: 'my-term',            // 唯一 id / 고유 id（英文小写、连字符）
  c: 'ptr',                // 主题 id / 주제 id（见 CATS / CATS 참고）
  z: '中文术语',            // 中文 / 중국어
  k: '한국어 용어 (별칭)',   // 한국어 / 韩语（括号内为别称）
  e: 'english term',       // English
  dz: '中文解释。',          // 中文说明 / 중국어 설명
  dk: '한국어 설명.',        // 韩语说明 / 한국어 설명
  x: ['int a = 1;', '// 示例代码，可省略 / 예시 코드, 생략 가능'] }
```

- 主题在 `CATS` 数组里，知识点文章在 `TOPICS` 数组里，界面文字在 `STR` 里。
- 주제는 `CATS`, 지식 포인트 글은 `TOPICS`, UI 문구는 `STR` 배열에서 수정합니다.

순수 HTML + CSS + JavaScript, 빌드 과정과 의존성 없음. 글꼴은 Google Fonts(IBM Plex Sans KR, IBM Plex Mono, Noto Sans SC)를 쓰며 오프라인에서는 시스템 글꼴로 대체됩니다.
